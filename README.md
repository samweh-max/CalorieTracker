# Samslimmer

A friendly, phone-first calorie, macro, fibre and water tracker. Inspired by Lose It!

- Works in any modern phone browser and can be added to the home screen like an app.
- Everything you log is saved **on your own phone** (in the browser). Nothing is uploaded.
- Light and dark mode, plus **backup & restore** (Me › Your data) so a cleared browser never loses your log.
- Food search: built-in everyday basics, Open Food Facts (UK or Canada products) and Health Canada's Canadian Nutrient File.

## Put it online with GitHub Pages
1. Create a new public repository on GitHub, e.g. `samslimmer`.
2. Upload every file and folder from this folder (keep the folder structure).
3. In the repository: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save**.
4. After a minute your app is live at `https://<your-username>.github.io/samslimmer/`.
5. On your phone open that link, then **Share → Add to Home Screen** (iPhone) or **⋮ → Install app / Add to Home screen** (Android).

## Data sources
- Open Food Facts — https://world.openfoodfacts.org (Open Database Licence)
- Canadian Nutrient File, Health Canada — Open Government Licence – Canada
- Built-in basics are typical average values, rounded.
